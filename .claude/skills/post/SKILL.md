오늘 날짜를 기준으로 `_posts/` 폴더에 새 블로그 포스트 파일을 생성해줘.

사용자가 주제만 말하더라도 추가 질문 없이 제목, 카테고리, 태그, 내용을 모두 채워서 바로 파일을 만들어줘.
사용자가 명시적으로 제공한 정보는 그대로 쓰고, 나머지는 주제에서 추론해서 채울 것.

## 파일명 규칙

`YYYY-MM-DD-{title을-영어-소문자-kebab-case로}.md`

## frontmatter 형식

```yaml
---
title: {제목}
date: YYYY-MM-DD HH:MM:SS +0900
categories: [{상위 카테고리}, {하위 카테고리}]
tags: [{태그1}, {태그2}]
---
```

## 카테고리 규칙

- categories는 최대 2개 (Chirpy 제한)
- 기존 카테고리를 우선 사용해서 일관성을 유지할 것

**현재 사용 중인 카테고리:**

| 상위 | 하위 | 용도 |
|------|------|------|
| AI | Claude | Claude Code, AI 개발 도구 관련 |
| 개발 | AI | AI 활용 개발 일반 |
| 개발 | 성능 | 프론트엔드 성능 최적화 |
| 개발 | 테스트 | 테스트 코드, QA |
| 개발 | Flutter | Flutter/Dart 개발 |
| Career | Interview | 취업, 면접 준비 |
| CodingTest | Hash | 코딩테스트 해시 문제 |
| Study | Algorithm | 알고리즘 학습 정리 |

## 태그 규칙

- 기술 키워드는 영어 소문자: `performance`, `flutter`, `claude`, `ai`
- 코딩테스트/알고리즘 관련은 한국어 허용: `코딩테스트`, `해시`, `배열`
- 기존 포스트에서 쓰인 태그를 재사용해서 일관성을 유지할 것

## 제목 패턴

- 카테고리 prefix 방식: `[알고리즘] 제목`, `[해시] 제목` — 코딩테스트/학습 포스트에 사용
- 시리즈 방식: `제목 (1) — 부제`, `제목 (2) — 부제` — 여러 편으로 나뉘는 포스트에 사용
- 일반: prefix 없이 바로 제목

## 내용 작성 틀

아래 구조를 기준으로 작성할 것.

```
## 도입부 (제목 없이 또는 배경 섹션)
왜 이 글을 쓰는지, 어떤 문제에서 출발했는지를 2~3문장으로 시작.
직접적으로 핵심을 언급할 것. 길게 늘어지지 않게.

---

## 본문 섹션 1

## 본문 섹션 2

...

---

## 마무리 (선택)
실용적인 결론 또는 다음 단계 제안.
```

**작성 스타일:**
- 1인칭, 경험 기반 서술
- 짧고 직접적인 문장
- 이론보다 실용적 내용 위주
- 코드 블록에는 언어 명시: ` ```javascript `, ` ```bash ` 등
- Chirpy 전용 강조 블록 활용:
  - `{: .prompt-info }` — 참고/부연 설명
  - `{: .prompt-tip }` — 팁/권장 방법
  - `{: .prompt-warning }` — 주의사항
  - `{: .prompt-danger }` — 위험/오류 유발 패턴
- `---` 구분선으로 섹션 사이 시각적 여백 추가

## 분량 및 시리즈 판단

- 포스트 한 편의 적정 분량은 **1,000~2,000자** (읽는 데 5~10분)
- 주제가 방대해서 한 편에 담기 어려우면 자동으로 시리즈로 분리할 것
  - 시리즈로 판단하는 기준: 주요 섹션이 4개를 넘거나, 각 섹션이 독립적으로 완결될 수 있을 때
  - 분리 시 제목은 시리즈 방식(`제목 (1) — 부제`)으로 짓고, 각 편을 순서대로 모두 생성
  - 1편 마지막에 다음 편 예고, 2편 이후 첫 줄에 이전 편 링크 추가

## 기타 규칙

- 사용자가 내용을 직접 제공하면 그대로 사용하고, 없으면 주제에 맞게 초안을 작성해줄 것
- 같은 날짜에 같은 주제의 파일이 이미 있는지 확인 후 생성

## 완료 후 요약

파일 생성이 완료되면 아래 항목을 사용자에게 요약해줄 것:

- **파일명**: 생성된 파일 경로
- **제목**: 포스트 제목
- **카테고리 / 태그**
- **섹션 구성**: 작성된 본문의 주요 섹션 목록
