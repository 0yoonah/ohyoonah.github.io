코딩테스트 공부를 시작하려는데 뭐부터 해야 할지 모르겠다. LeetCode를 해야 하나, 프로그래머스를 해야 하나, 책을 사야 하나. 선택지가 너무 많아서 오히려 아무것도 안 하게 됐다. 이 시리즈는 그 막막함을 정리하면서 같이 시작해보려고 쓴다.

## 언어 선택

가장 먼저 결정해야 했던 것. 결론은 **이미 쓸 줄 아는 언어로 하면 된다**는 것이다.

- **Python**: 코드가 짧고 내장 라이브러리가 강력하다고 한다. `collections`, `heapq`, `itertools` 등을 활용하면 구현이 빠르다는데, 단점은 속도라고. 시간 제한이 빡빡한 문제에서 PyPy로 제출해야 하는 경우가 있다고 한다.
- **JavaScript**: 프로그래머스와 LeetCode 모두 잘 지원한다. 나는 웹 개발을 하고 있어서 가장 익숙한 JavaScript로 시작하기로 했다.
- **Java**: 속도가 빠르고 타입이 명확해서 실수가 줄어든다고 하는데, 코드가 길어진다는 단점이 있다.
- **C++**: 네 언어 중 실행 속도가 가장 빠르다고 한다. 하지만 러닝커브가 있어서 익숙하지 않다면 굳이 새로 배울 필요는 없을 것 같다.

언어 때문에 못 푸는 문제는 없다고 하니, 일단 익숙한 언어로 시작하는 게 맞는 것 같다.

> JavaScript는 기본 `sort()`가 문자열 기준으로 동작하는 함정이 있고, 힙(우선순위 큐)을 직접 구현해야 한다는 점을 알아두자.

## 플랫폼 선택

### 프로그래머스

국내 채용 코테와 가장 가까운 환경이라고 한다. 실제로 많은 회사가 프로그래머스 플랫폼을 그대로 사용한다고 해서 일단 여기서 시작해보려 한다. 레벨별(0~5)로 잘 정리되어 있어서 단계적으로 올라가기 좋을 것 같다.

→ **취업 준비, 실전 감각 익히기에 좋다고 한다.**

### LeetCode

전 세계에서 가장 많이 쓰는 알고리즘 플랫폼이라고 한다. 문제 수가 많고 유형별 분류가 잘 되어 있다. 외국계 기업이나 글로벌 공고를 노린다면 필수라는 말도 많다. 영어로 되어 있는 게 처음엔 좀 걸리지만 익숙해지면 문제없을 것 같다.

→ **알고리즘 유형별 집중 훈련, 외국계 준비에 좋다고 한다.**

### 일단 이렇게 해볼 생각

프로그래머스로 실전 감각을 익히고, LeetCode로 알고리즘 유형별 훈련을 병행하는 방식으로 해볼 생각이다.

## 일단 알아야 할 자료구조와 알고리즘

처음부터 모든 걸 다 공부하려면 끝이 없을 것 같아서 우선순위를 정해봤다.

### 1순위 — 일단 여기서부터

| 항목 | 이유 |
|------|------|
| 배열, 문자열 | 모든 문제의 기반 |
| 해시맵 | 탐색 O(1), 빈도 계산 |
| 스택, 큐 | 괄호, BFS/DFS 기반 |
| BFS / DFS | 그래프, 탐색 문제의 핵심 |
| 정렬 | 내장 sort + 커스텀 조건 |

### 2순위 — 어느 정도 익히면 좋을 것 같은

| 항목 | 이유 |
|------|------|
| DP (동적 프로그래밍) | 중~상 난이도 문제에 자주 등장한다고 한다 |
| 이분탐색 | 탐색 범위를 좁히는 핵심 기법 |
| 힙 (우선순위 큐) | 최소/최대 추출 |
| 그리디 | 조건에 따라 최적 선택 반복 |

### 3순위 — 나중에 봐도 될 것 같은

트라이, 세그먼트 트리, 위상 정렬, 최단 경로(다익스트라, 벨만포드) 등은 기초가 좀 쌓이면 그때 봐도 늦지 않을 것 같다.

## 처음 4주 플랜

| 주차 | 목표 | 플랫폼 |
|------|------|--------|
| 1주차 | 배열, 문자열, 해시 기본 문제 | 프로그래머스 Lv.1 |
| 2주차 | 스택, 큐, BFS/DFS 입문 | LeetCode Easy |
| 3주차 | BFS/DFS 응용, 정렬, 그리디 | LeetCode Easy~Medium |

하루에 무조건 많이 풀기보다는 **1~2문제를 제대로 이해하는 게 낫다**는 말을 많이 봤다. 틀렸을 때 왜 틀렸는지 분석하는 게 중요할 것 같다.
